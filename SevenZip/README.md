# 7-Zip 26.02

Source: [7-Zip 26.02](https://github.com/ip7z/7zip/tree/26.02).

The unmodified files here implement the upstream Format7z bundle, with portable C implementations of its optimized routines and Unix platform support. Detours uses its stream interface so the operation helper creates and owns archive output handles. No RAR handler is included.
