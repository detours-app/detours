Detours - Code Audit

2026-07-10 · 310 Swift source files · 5 review agents, 34 raw findings, 13 cleared the confidence threshold of 80
A

All thirteen findings are fixed and verified: build clean, swiftlint clean, and every affected test suite green. No findings remain open above the confidence threshold.

Summary

The audit found two problems that can cost a user their data or their session. A cut-and-paste into the folder a file already lives in is treated as a name collision with itself; choosing "Replace" moves the original to the Trash and then fails, leaving the folder empty of the file the user was trying to keep. Separately, the remote helper daemon can be wedged indefinitely by an archive tool that writes enough diagnostic output, because the helper waits for the tool to finish before it ever reads what the tool is saying, and the tool cannot finish until someone reads it. Every later request on that connection stalls behind it.

Six further findings are real but bounded. An interrupted copy to a remote host restarts from the beginning on reconnect and duplicates everything it had already transferred under numbered names. Git status badges silently fail to appear for any file whose name contains a non-ASCII character, because the local parser never learned the escaping that the remote parser already handles. Archive passwords on Windows hosts are still passed on the command line where any other local account can read them, even though the same exposure was closed on the macOS and Linux paths. A password dialog is shown for encrypted archives that the app then unconditionally refuses to open.

The five Minor findings are unreachable guard clauses, a no-op branch, an unbounded icon cache, and a missing pre-check that turns a rename collision on a remote host into a raw error alert instead of the polite refusal the local path gives. Twenty-one further candidate findings were verified and discarded as false positives or nitpicks; four more landed at confidence 75, just under the threshold, and are not reported here.

All thirteen were fixed in the same pass. A same-folder move now short-circuits to a no-op on both the fast and heavy lanes, so nothing reaches the Trash. The remote helper drains a child process's output while it runs rather than after it exits, on both the archive and git paths. Remote copy transfers one item per request and remembers what already landed, so a reconnect resumes rather than restarts. The app decodes git's C-style filename escaping the same way the helper does, with a test that fails if the two ever diverge again. Archive passwords are refused on the Windows backend as they already were everywhere else, and the dialog that collected them is gone. The icon cache evicts under memory pressure, remote rename refuses a taken name without an alert, and the unreachable guards and the no-op branch are deleted. Build and swiftlint are clean and every affected test suite passes.
